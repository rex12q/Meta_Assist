(작성자 = 본인)

오류: (26.11.11 ~ 26.11.22)
1. 데이터 누수
상세 내용: 작성자는 학습을 위해 국내 의료 기준을 일부분만 참고하여 조건을 세웠다.(뒤에 문제점 2와 이어진다.) 그러나 조건에서 나타난 feature는 AI가 학습을 하는 공간에 그대로 기입이 되어 데이터 누수가 발생하게 되었다. 이렇게 될 경우 데이터를 학습하여도 작성자가 적은 조건을 외워 관련이 있는 feature를 무시하고 단순히 조건을 외운 잘못된 결과 수치가 나오게 된다.

2. 공식 지침서를 전부 확인하지 않고 기준을 설계
상세 내용: 작성자는 공식 지침서를 똑바로 읽고 기준을 세워야 했으나 그러질 못했다. 클래스 3단계(정상, 주의, 고위험) 기준은 사용자가 임의로 설계한 클래스이다. 대사증후군 진단 필수 항목으로는 중성지방, HDL(고밀도 지단백), 혈압, 공복혈당, 허리둘레가 들어가는게 맞으나 작성자는 공복혈당, 혈압, 허리둘레만을 갖고 설계했다. 학습에 사용된 데이터는 HP 이상지질혈증 (표준 확진 기준), DSP 이상지질형증 (간이 검사 키트)가 있다. 두 항목 중에선 HP를 종속변수 y 생성 조건에 들어가야 했었다. 

3. 이름 변경, 조건문 구조 수정
상세 내용: '대사증후군'이라는 키워드를 붙이면 안된다. 앞서 모든 기준을 제대로 확인하지 않고 작성자 마음대로 설계했기 때문이다. 조건문에선 WC(허리둘레) 양성 기준을 넘은 판정, 그리고 이하 항목에서 전부 음성 기준을 넘은 판정을 받아도 데이터가 고위험(2)으로 분류가 된다. 코드 내에 존재하는 danger_score >= 1 |(OR)는 앞서 언급한 WC가 danger_score에 할당되어 있기 때문에 삭제해야 한다. 

4. 무분별 0, 1로 바꾸는 전처리
상세 내용: 데이터를 구성하는 항목은 무조건 순서가 없거나 의미가 없는 범주형으로 분류가 되어 있지 않다. 작성자는 의미가 있는 범주형 데이터도 같이 전처리를 진행했다. 그러므로 의미가 있는 범주형은 그저 의미가 없는 전처리된 항목으로 바뀌게 되었다. (AgeGroup, Education)

5.출력된 결과에만 의존
상세 내용: classification_report 모듈을 통해 재현율(데이터 내 진짜 양성 중 모델이 판단한 양성), 정밀도(모델이 판단한 양성 중 진짜 양성)만 확인하였다. 이 데이터는 불균형, 균형이여서 나온 결과인지, 어떠한 근거를 기반으로 이런 결과가 출력됐는지를 아예 의심 안 하고 그저 출력된 결과에만 집중하였다.
6.(중복) 데이터를 설명하는 메타데이터 확인 X
상세 내용: 데이터의 핵심 내용인 메타데이터를 확인하지 않고 대충 넘겼다. 간단하게 속성명과 속성값을 확인한 후 데이터를 다뤘으며 가장 큰 문제이다.
